# CA Mantra — Landing Page Design Concepts

Landing page design mockups for **CA Mantra**, prepared by **Web Spider Solutions** for client review and approval.

> ⚠️ **For presentation purposes only.** These are visual design concepts — not the final production website. The approved design will be developed into a full production build in a separate project.

## What's Inside

Each folder contains self-contained landing page design concepts:

```
business-loan/
  index.html   → Preview entry page (compare designs)
  v1/          → Design V1: Classic Corporate (navy + steel blue, dark photo overlays)
  v2/          → Design V2: Light Premium (white + soft blue, large rounded photos, floating badges)
```

Two earlier concepts (the original dark-fintech V2 and Minimal Editorial V3) were removed; they remain in git history if ever needed.

Each design folder has an `index.html` (the landing page) and a `thank-you.html` (the page shown after the form is submitted).

## How to Review

1. Open `business-loan/index.html` in any modern browser (or open a specific design's `index.html` directly).
2. Resize the browser window or open on a phone to see the responsive/mobile view.
3. Note the design name/folder when giving feedback (e.g., "Design 2, but with the hero section from Design 1").

No installation, build step, or server is required — the pages open directly in the browser.

## Notes for Reviewers

- Some figures are **sample values** (sanction days, turnover figures, phone numbers, office address, working hours) — they read as normal text in the designs and will be replaced with confirmed numbers before the production build.
- All three designs follow the brand logo's color palette (steel blue, black, white).
- Forms are **visual previews** — they validate input and show the thank-you page, but do not send data anywhere yet.
- Feedback on colors, layout, typography, imagery style, and overall feel is what we're looking for at this stage.
